# 実機での動作確認チェックリスト(iOS / Android)

dev(検証環境)で確認してから、本番にデプロイします。

## 基本
- [ ] 新規登録(表示名・ログインID・パスワード)→ そのままメイン画面
- [ ] ログアウト → 「オーナーでログイン」でID・パスワードでログイン(間違ったときのエラー)
- [ ] メンバー: 「メンバーで参加」→ 参加コード → IDとパスワードを作成 → ログアウト → 「メンバーで参加 → IDとパスワード」で入れる
- [ ] メンバーのIDを「オーナーでログイン」に入れると、案内が出る(逆も同様)
- [ ] IDとパスワードが分からないメンバーが、コードで入れる(入ったあとに既存のログインIDが表示される)
- [ ] 設定でログインID・パスワードの変更(変更後、他の端末がログアウトされる)
- [ ] 明細の作成(支出/収入の切り替え、金額は100円単位の増減、¥とカンマ表示)
- [ ] 明細をタップして編集、ゴミ箱ボタンで削除(確認モーダル)
- [ ] レシート画像の添付(撮影・選択)と表示。ファイル選択ボタンが中央に表示される
- [ ] 集計タブ: 初期表示が今月。「詳細検索」で種別・カテゴリ(複数)が開閉する。閉じていても効いている条件が見える。「条件をリセット」で初期状態に戻る。合計行
- [ ] 明細タブ: 集計と同じ年・月の選択(年間も可)、詳細検索(種別・キーワード)、リセット
- [ ] 円グラフをタップ → 内訳と明細(カテゴリで絞り込み、明細をタップして編集)
- [ ] 予算: 合計の不一致で保存できない、リセット
- [ ] セレクトの「v」が枠の中に表示される、ヘッダの「更新」で開いていたタブのまま再読み込み
- [ ] `/detail` が明細タブ(`/tx` からは自動で移動)

## メンバー・設定
- [ ] メンバー招待(備考・権限を決めてコード発行 → 参加 → 備考・権限の編集、削除)
- [ ] CSVの書き出し(入力者IDの列がある)→ CSVの取り込み(確認画面 → 取り込み、エラー行の表示)
- [ ] カテゴリのアイコン変更

## オフライン・引き継ぎ・通知(実機が必要)
- [ ] 機内モードで明細を入力 → 復帰後に「未同期」が消える / 同期エラーの再送・破棄
- [ ] **iOS**: Safari でログイン → 設定の「ホーム画面に追加する準備」→ 共有 → ホーム画面に追加 → アプリ初回起動で自動ログイン(うまくいかなければ端末追加コード・QR)
- [ ] 通知: ホーム画面アプリで通知を許可 → 管理者のお知らせ / 問い合わせへの返信 / 予算80%・100%
- [ ] アプリの更新通知(新しいバージョンがあります。画面と同じデザインのモーダル)
- [ ] **iOS**: ホーム画面のアイコンが表示される(PNGアイコン)

## 管理者画面
- [ ] `/admin` で、管理者パスワードと確認コードでログインできる(ログアウト後は入れない)
- [ ] 問い合わせの返信、お知らせの作成(予約配信を含む)、メンバー検索
- [ ] 復旧申請の確認・統合(統合後、申請者がログインID/パスワードで旧家計簿に入れる)

## 確認できていないこと(開発時点)
自動テストで確認したのは、API と同期・統合などのロジックです。次は実機・実環境で未確認です。
- ブラウザ上の画面表示と操作全般、iOS のホーム画面アプリの挙動
- 実際のプッシュサービス(FCM・APNsなど)への配信と通知の表示
- Turnstile の成功ケース、パスワード照合の処理時間(無料プランの CPU 時間の上限。出る場合は有料プランが必要)
- 管理者ログインの確認コード(認証アプリとの実際の連携。サーバー側の計算はテスト済み)
- Background Sync(バックグラウンド送信): Chrome/Android のみ。アプリを閉じた状態で、機内モードの解除後に送信されるか
